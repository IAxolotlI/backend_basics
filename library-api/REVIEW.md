# Саморевью по финальному чек-листу

## Ресурсы и URL
- [x] **Path:** существительные, множественное число, kebab-case (`/books`, `/readers`, `/loans`).
- [x] **Нет глагольных URL:** кроме осознанных действий вроде `/loans/{id}/return`.
- [x] **id конкретного ресурса в path, фильтры - в query:** `/loans/{id}`, `/loans?status=overdue`.
- [x] **Версия API указана в servers:** `https://api.library.example/v1`.

## Методы и коды
- [x] **POST:** создание возвращает `201` + заголовок `Location` (описано для создания книг и читателей).
- [x] **DELETE:** возвращает `204` без тела.
- [x] **Пустой список:** возвращает `200` + пустой массив `items: []` (не 404).
- [x] **Бизнес-конфликт:** возвращает `409`, ошибка валидации — `422`.

## Ошибки и списки
- [x] **Все ошибки используют один ErrorResponse:** схема `ErrorResponse { code, message, details }`.
- [x] **Для 422 есть example с details:** добавлен пример `validation` с указанием поля.
- [x] **На коллекциях есть фильтры, сортировка и пагинация:** реализовано для книг, читателей и выдач.
- [x] **limit имеет default и maximum:** параметр `limit` (default: 20, maximum: 100).

## Документация
- [x] **Operations имеют summary, description, tags:** заполнено для всех эндпоинтов.
- [x] **Есть examples успеха и типичной ошибки:** добавлены examples для 201 (создание), 200 (списки), 409 (конфликт), 422 (валидация).
- [x] **Общие схемы подключены через $ref, не скопированы руками:** все Request/Response ссылаются на `components/schemas`.
- [x] **Файл OpenAPI валидируется без ошибок:** синтаксис OpenAPI 3.1 соблюден.
